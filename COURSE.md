# Карта курса

Курс состоит из 13 небольших заданий. Задания 1–7 объясняют sweep line, 8–11 — DCEL,
12–13 собирают всё в map overlay.

| № | Тема | Что должно «щёлкнуть» |
|---:|---|---|
| 01 | Orientation predicate | знак векторного произведения кодирует left/right/collinear |
| 02 | Два отрезка | пересечение — классификация, а не только точка |
| 03 | Event queue | алгоритм живёт только в дискретных событиях |
| 04 | Sweep status | вертикальное положение превращается в порядок слева направо |
| 05 | Соседи | проверять нужно только пары, которые стали соседями |
| 06 | Bentley–Ottmann | новые пересечения сами становятся будущими событиями |
| 07 | Совпавшие события | одна точка обрабатывает множества U, L и C |
| 08 | Half-edge/DCEL | одно ребро имеет две направленные стороны |
| 09 | Обход DCEL | Next/Prev кодируют границы, Twin — переход на другую сторону |
| 10 | Split edge | пересечение физически разрезает топологическое ребро |
| 11 | Cycles and holes | контуры нужно сгруппировать во внешние границы и отверстия |
| 12 | Face labels | область overlay знает, из каких исходных областей она получена |
| 13 | Boolean operations | union/intersection/difference — фильтрация размеченных ячеек |

## Темп

Рекомендуемый размер одной сессии — одно задание за 30–90 минут. Не переходите дальше, пока
не можете устно объяснить инвариант текущей структуры данных и пока тест урока не проходит.

## Финальная модель

После задания 13 попробуйте без кода объяснить весь pipeline:

1. В очередь попадают концы сегментов.
2. Статус хранит активные сегменты слева направо.
3. Новые соседства порождают проверки пересечений.
4. Пересечение добавляется как будущее событие и меняет порядок сегментов.
5. Найденные точки разрезают рёбра двух DCEL.
6. Полурёбра связываются в циклы, циклы — в faces.
7. Faces получают метки исходных карт.
8. Boolean operation выбирает faces по меткам.

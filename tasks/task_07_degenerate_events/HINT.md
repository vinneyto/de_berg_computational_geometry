# Подсказка

Для каждого сегмента относительно точки `p` проверьте три взаимоисключающих случая:

- `U(p)` — *upper endpoints*: верхние концы в `p`;
- `L(p)` — *lower endpoints*: нижние концы в `p`;
- `C(p)` — *containing segments*: сегменты, содержащие `p` строго во внутренности.

Сначала сравните `p` с `segment.upper` и `segment.lower`. Только если это не endpoint
(*конечная точка*), проверяйте принадлежность внутренности через `point_on_segment`.

Точка является пересечением, если размер объединения `U(p) ∪ L(p) ∪ C(p)` больше одного.
Использование `frozenset` делает результат неизменяемым и позволяет безопасно сравнивать его
в тестах.

Частая ошибка: одновременно помещать endpoint в `C(p)`.

# 07. Несколько сегментов в одной точке

У красивого алгоритма из прошлого урока ломаются предположения: три рёбра могут встретиться
в одной точке, intersection может совпасть с endpoint, а несколько endpoint — между собой.

Поэтому событие `p` обрабатывает множества:

- `U(p)` — сегменты с верхним концом в `p`;
- `L(p)` — сегменты с нижним концом в `p`;
- `C(p)` — сегменты, содержащие `p` во внутренности.

Если объединение содержит больше одного сегмента, `p` является пересечением. Все `L` и `C`
удаляются из статуса, затем `U` и `C` вставляются в порядке чуть ниже события.

## Задание

Реализуйте классификацию сегментов относительно события. Горизонтальный сегмент считайте
имеющим левую точку как `upper`, следуя tie-break книги.

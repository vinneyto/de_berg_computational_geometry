# Подсказка

Соберите алгоритм из уже знакомых операций, а не пишите одну большую функцию.

1. Добавьте в очередь верхние и нижние концы всех сегментов.
2. Держите активные сегменты в статусе слева направо.
3. После локального изменения статуса получите новые соседние пары.
4. Проверьте каждую такую пару ровно один раз для текущего соседства.
5. Если единственное пересечение находится ниже текущего события, добавьте его в очередь.
6. В событии пересечения перестройте порядок на уровне чуть ниже точки.

Храните множество уже запланированных пар и точек, иначе одно пересечение может несколько
раз попасть в очередь. `tested_pairs` увеличивайте только при реальном геометрическом тесте.

Bentley–Ottmann — фамилии авторов алгоритма, а не аббревиатура. Его главный инвариант:
все пересечения выше текущей sweep line (*заметающей прямой*) уже обработаны.

# 06. Bentley–Ottmann в общем положении

Теперь структуры соединяются в цикл:

1. очередь отдаёт следующее событие;
2. статус обновляется чуть ниже события;
3. проверяются новые соседние пары;
4. найденное пересечение ниже текущей точки добавляется в очередь;
5. пересечение позднее меняет порядок в статусе и раскрывает следующие пары.

В этом задании можно предполагать общее положение: нет горизонтальных сегментов, общих
концов, наложений и тройных пересечений.

## Задание

Реализуйте `find_intersections`. Разрешается переиспользовать код предыдущих упражнений,
но не делать двойной цикл по всем парам. Счётчик `tested_pairs` нужен, чтобы увидеть
разницу между candidate generation и brute force.

## Инвариант

После извлечения события все пересечения выше него уже известны.

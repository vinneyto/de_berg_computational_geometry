# Подсказка

Соседние пары порядка удобно получить через:

```python
zip(order, order[1:])
```

Каждую пару прогоните через `canonical_pair`, которая возвращает элементы в одном и том же
порядке независимо от их геометрического положения.

После этого задача `newly_adjacent` превращается в разность множеств:

```text
adjacent_pairs(after) - adjacent_pairs(before)
```

Не генерируйте все сочетания элементов. Смысл упражнения именно в том, что линейный порядок
из `n` сегментов содержит не больше `n - 1` соседних пар.

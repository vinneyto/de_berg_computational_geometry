# Подсказка

Python `heapq` является min-heap — первым возвращается наименьший ключ. Чтобы обрабатывать
больший `y` раньше, используйте ключ `(-y, x)`.

Одного heap недостаточно: он не умеет быстро ответить, существует ли событие с такими
координатами. Держите рядом словарь:

```text
Point → Event
```

При первом `push` создайте `Event`, положите его в словарь и добавьте координатный ключ в
heap. При повторном `push` только объедините `kinds` и `segment_names` существующего события.

При `pop` извлеките ключ, найдите объект в словаре и удалите его оттуда. Значение `bool(queue)`
может определяться непустотой словаря.

Аббревиатур в этом задании нет: `heap` означает двоичную кучу, а не очередь FIFO
(*first in, first out* — «первым вошёл, первым вышел»).

# Подсказка

Сначала соберите все границы входных полигонов. `unary_union` разрежет линии в точках
пересечения, после чего `polygonize` соберёт замкнутые ячейки.

Для каждой ячейки возьмите `representative_point()`: в отличие от центра bounding box
(*ограничивающего прямоугольника*) эта точка гарантированно лежит внутри сложного полигона.

Затем пройдите по входным `LabeledPolygon` и добавьте `(layer, label)`, если их полигон
содержит точку. Отсортируйте метки перед созданием tuple, чтобы результат был устойчивым.

Не используйте готовые Boolean operations для непосредственного построения ответа: цель
упражнения — увидеть, что overlay сначала создаёт атомарные ячейки, а уже затем переносит
на них семантику исходных слоёв.

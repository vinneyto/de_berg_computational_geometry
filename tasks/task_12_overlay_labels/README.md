# 12. Метки областей overlay

Геометрическое overlay разбивает плоскость на более мелкие ячейки. Но смысл появляется
только после маркировки каждой ячейки исходными faces, которые её содержат.

Например, ячейка может иметь метки:

`{"vegetation": "pine", "rainfall": "1000-1500"}`.

В упражнении Shapely выполняет polygonization уже нарезанных границ. Ваша задача — выбрать
внутреннюю representative point каждой ячейки и перенести на неё метки входных полигонов.
Так разделяются две ответственности: библиотека строит геометрию, вы строите семантику.

## Инвариант

Каждая output-cell знает все входные области, которые содержат её внутреннюю точку.

## Запуск теста

```bash
uv run pytest tasks/task_12_overlay_labels/test_exercise.py
```

# 09. Обход границ в DCEL

Связи `next` превращают разрозненные полурёбра в цикл границы. Связи `twin` позволяют
перейти через ребро в соседнюю грань. Это две разные формы навигации.

В упражнении готовая фабрика создаёт DCEL простого многоугольника. Вам нужно реализовать:

- обход полурёбер одной границы;
- извлечение координат её границы;
- перечисление исходящих рёбер вершины через `twin.next`.

## Защита от ошибок

Каждый обход должен остановиться при возвращении к стартовому объекту и иметь ограничение
числа шагов, чтобы повреждённый DCEL не создавал бесконечный цикл.

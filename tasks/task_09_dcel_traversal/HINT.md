# Подсказка

DCEL — *doubly-connected edge list* (двусвязный список рёбер). `CCW` означает
*counterclockwise* — против часовой стрелки; `CW` означает *clockwise* — по часовой.

Для `walk_boundary`:

1. запомните стартовое полуребро;
2. добавляйте текущее ребро в результат;
3. переходите по `next`;
4. остановитесь, когда снова получили стартовый объект через сравнение `is`.

Если `next is None` или число шагов превысило `max_steps`, структура повреждена — выбросьте
ошибку вместо бесконечного цикла.

`boundary_points(face)` — это `origin.point` всех рёбер обхода от `outer_component`.

Чтобы обойти исходящие рёбра вокруг вершины, начните с `incident_edge` и повторяйте переход
`edge.twin.next`: twin переносит на другую сторону ребра, next поворачивает вокруг вершины.

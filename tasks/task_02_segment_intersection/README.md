# 02. Пересечение двух отрезков

Пересечение — это не всегда одна аккуратная точка. Возможны три результата:

1. пересечения нет;
2. есть одна точка — в том числе общий конец;
3. коллинеарные отрезки перекрываются целым интервалом.

Сначала примените четыре orientation-предиката. В общем случае концы каждого отрезка
лежат по разные стороны от прямой другого. Коллинеарные случаи обработайте отдельно.

## Задание

Реализуйте классификацию и вычисление единственной точки через параметрические уравнения
`A + t(B-A) = C + u(D-C)`. Для `OVERLAP` возвращать бесконечное множество точек не нужно.

## Проверка себя

Объясните, почему общий endpoint считается пересечением в задаче про наложение карт.

# Подсказка

Сначала вычислите четыре ориентации:

```text
orientation(A, B, C)
orientation(A, B, D)
orientation(C, D, A)
orientation(C, D, B)
```

Если первые две имеют разные знаки и последние две имеют разные знаки, пересечение
единственное и находится во внутренности обоих отрезков.

Затем отдельно обработайте нулевые ориентации через `point_on_segment`. Если коллинеарные
отрезки имеют больше одной общей точки, результат — `OVERLAP`, а не `POINT`.

Для единственной точки запишите `A + t(B - A)` и найдите `t` через двумерные векторные
произведения. Проверьте знак знаменателя: нулевой знаменатель означает параллельность.

Частая ошибка: раньше времени округлять координаты точки пересечения.

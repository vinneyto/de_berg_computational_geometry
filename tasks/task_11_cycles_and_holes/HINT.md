# Подсказка

Используйте формулу шнуровки (*shoelace formula*):

```text
area2 = Σ(x_i * y_{i+1} - x_{i+1} * y_i)
signed_area = area2 / 2
```

Положительная площадь означает `CCW` (*counterclockwise*, против часовой стрелки),
отрицательная — `CW` (*clockwise*, по часовой стрелке).

В `group_cycles` сначала разделите внешние `CCW`-циклы и `CW`-отверстия. Для каждого
отверстия:

1. возьмите внутреннюю representative point (*репрезентативную точку*) полигона;
2. найдите все внешние полигоны, которые её содержат;
3. выберите содержащий полигон с наименьшей площадью.

Последний шаг назначает отверстие ближайшему контейнеру, а не самому большому внешнему циклу.

# 11. Граничные циклы и отверстия

После разрезания и связывания полурёбер мы получаем циклы, но ещё не faces. Нужно понять,
какие циклы являются внешними границами, а какие — отверстиями.

Signed area даёт ориентацию цикла. Для CCW-контура площадь положительна, для CW —
отрицательна. Затем отверстие назначается наименьшему внешнему контуру, который его содержит.

В книге для эффективного связывания используется информация, собранная sweep line, и граф
циклов. Здесь сначала реализуется более прозрачная версия через point-in-polygon.

## Задание

Реализуйте signed area, классификацию ориентации и группировку отверстий. Готовый Shapely
можно использовать только для `contains`, не для определения ориентации.

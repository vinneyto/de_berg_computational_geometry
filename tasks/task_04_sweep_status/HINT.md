# Подсказка

Для негоризонтального отрезка найдите параметр:

```text
t = (y - start.y) / (end.y - start.y)
x = start.x + t * (end.x - start.x)
```

Для вертикального отрезка формула тоже работает. Горизонтальный случай требует заранее
выбранного соглашения; для этого упражнения достаточно вернуть левый `x`.

`SortedList` из пакета `sortedcontainers` сортирует элементы по ключу в момент вставки.
Но ключ зависит от `self.y`. Поэтому при `set_y`:

1. сохраните обычный список сегментов;
2. измените `y`;
3. очистите и заново заполните `SortedList`.

Для поиска соседей найдите индекс сегмента. Левый сосед имеет индекс `i - 1`, правый —
`i + 1`, если они существуют.

В теоретическом алгоритме вместо перестроения используется BST (*binary search tree*,
двоичное дерево поиска), обычно сбалансированное.

# Подсказка

Начните с одной величины:

```text
(b.x - a.x) * (c.y - a.y) - (b.y - a.y) * (c.x - a.x)
```

Это удвоенная ориентированная площадь треугольника `ABC`. Её знак даёт направление
поворота. В `orientation` сравнивайте модуль результата с `eps` (`epsilon`, допустимая
погрешность): близкое к нулю значение считайте нулём.

Для `point_on_segment` нужны две независимые проверки:

1. точка коллинеарна концам отрезка;
2. её `x` и `y` попадают в AABB (*axis-aligned bounding box*, ограничивающий прямоугольник,
   выровненный по осям) отрезка с учётом `eps`.

Частая ошибка: считать любую коллинеарную точку принадлежащей конечному отрезку.

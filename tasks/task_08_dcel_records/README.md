# 08. DCEL и два полуребра

Набор сегментов ещё не является картой: он не знает, какое ребро идёт следующим по границе
и какая область находится с каждой стороны.

DCEL представляет геометрическое ребро двумя направленными half-edge. Для half-edge `e`:

- `origin` — начальная вершина;
- `twin` — то же ребро в обратном направлении;
- `next` / `prev` — соседи при обходе одной грани;
- `face` — грань слева от `e`.

## Задание

Создайте минимальные записи и свяжите пару близнецов. Используйте identity объектов, а не
сравнение всех полей dataclass: DCEL является графом со взаимными ссылками.

## Инварианты

`e.twin.twin is e`, а destination полуребра равен origin его twin.

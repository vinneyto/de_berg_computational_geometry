# 05. Новые соседства

Ключевой выигрыш sweep line появляется не из дерева как такового, а из геометрической
леммы: два пересекающихся отрезка перед встречей обязательно станут соседями.

Локальные изменения дают локальные проверки:

- insertion: новый отрезок проверяется с двумя соседями;
- removal: проверяются его бывшие левый и правый соседи;
- crossing: поменявшиеся местами отрезки проверяются с новыми внешними соседями.

## Задание

Функции получают порядок имён до/после события и должны вернуть только новые пары-кандидаты.
Пара канонизируется лексикографически, чтобы `(a, b)` и `(b, a)` не дублировались.

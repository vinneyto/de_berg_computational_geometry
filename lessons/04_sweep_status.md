# 04. Статус заметающей прямой

Статус содержит активные отрезки в порядке их пересечения с текущей горизонтальной
прямой. Для негоризонтального отрезка интерполируйте `x` по заданному `y`.

В production Bentley–Ottmann используют сбалансированное дерево. В упражнении применяется
готовый `SortedList`: при смене `y` статус перестраивается, чтобы явно показать зависимость
порядка от положения sweep line. Это медленнее теоретического алгоритма, но делает инвариант
видимым и тестируемым.

## Задание

Реализуйте `x_at`, изменение уровня, вставку/удаление и поиск соседей.

## Инвариант

Список всегда отсортирован по `x_at(segment, sweep_y)`, а затем по имени для устойчивости.

# 03. Очередь событий

Sweep line не движется непрерывно. Она прыгает по точкам, где меняется состояние:
верхним концам, нижним концам и найденным пересечениям.

Очередь должна:

- возвращать событие с наибольшим `y`;
- при равном `y` возвращать меньшее `x`;
- объединять несколько причин события в одной координате;
- не добавлять одну точку дважды.

Используйте готовый `heapq`. Учебная часть здесь — правильно определить ключ и отдельный
словарь для дедупликации, а не писать heap с нуля.

## Инвариант

В heap находится ровно одна актуальная запись для каждой ещё не обработанной точки.
